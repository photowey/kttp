# Kttp 1.2.0

## Added

- Import cURL commands and Postman Collections v2.0/v2.1 from the script editor or GUI, with preview and request selection.
- Import into the current script, saved GUI drafts or a new project-local script.
- Import optional Postman Environments, preserve existing profiles and choose whether to activate the imported environment.

## Improved

- Simplify GUI environment references to `${name}`, while retaining support for `${env:name}`.
- Improve the import dialog layout, imported-request selection and variable URL display.
- Fix script saving and environment lookup during import and GUI execution.

## Compatibility

IntelliJ IDEA 2026.3 (builds `263.0`–`263.*`). Postman JavaScript and OAuth flows require manual conversion.
