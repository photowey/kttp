# Kttp 1.0.0

Kttp is an HTTP client built around Kotlin scripts, with a command-line runner and an IntelliJ IDEA plugin.

## Features

- Write and run `.kttp.kts` requests with environment variables, local files, authentication and response assertions.
- Run an individual request or all registered requests from IntelliJ IDEA using the bundled CLI.
- Compose requests in the Kttp tool window. Follow Script retains script context; Quick Request sends supported HTTP data directly.
- Save GUI drafts, generate linked scripts, inspect response files and browse shared execution history.
- Discover saved responses automatically in the tool window, including files written outside the IDE's virtual file system.
- Use the bilingual English/Chinese documentation and the `kttp` coding-agent skill.

## Downloads

- `kttp-idea-1.0.0.zip`: install with **Settings → Plugins → Install Plugin from Disk…**. Includes the CLI runtime.
- `kttp-cli-1.0.0.jar`: standalone executable JAR with its compiler and runtime dependencies; JDK 21 is recommended.
- `kttp-docs-1.0.0.tar.gz`: built English and Chinese documentation.
- `SHA256SUMS`: SHA-256 digests of the three downloadable packages.

The plugin targets IntelliJ IDEA 2025.3.2 (`sinceBuild=253.0`). GitHub Releases are separate from JetBrains Marketplace publication.

## Current limits

- Quick Request skips Kotlin evaluation, script-level configuration and `then`; use Follow Script when these matter.
- HTTP and Postman import actions remain placeholders.
- The HTTP/2 option uses OkHttp's `H2_PRIOR_KNOWLEDGE`; it is not a general automatic HTTP/2 negotiation switch.
