# Kttp 1.0.1

This patch fixes IntelliJ IDEA compatibility issues affecting script dependencies and file navigation.

## Fixes

- Restore script editor dependencies on newer Kotlin plugins and retain dependency-library repair for existing projects.
- Open scripts and responses through supported platform APIs, including actions invoked from accessibility callbacks.
- Resolve the bundled CLI and script libraries from the installed plugin without internal plugin-manager APIs.
- Share scripting API classes with the IDE's Kotlin plugin to prevent class-loader conflicts in the editor.
- Report the current Kttp build version in default User-Agent headers for script and GUI requests.
- Remove unused Kotlin integrations and compiler-generated calls to deprecated or experimental platform methods.
- Keep response paths clickable in the Run console and provide the file-manager reveal action in their context menu.

## Compatibility

The plugin declares support for IntelliJ IDEA builds `253.0` through `263.*`. It retains the Kotlin scripting
`getDefinitionsClassPath` override required by IDEA 2025.3; this method is deprecated on IDEA 2026.3.
