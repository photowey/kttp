# Kttp 1.1.0

This release targets IntelliJ IDEA 2026.3, fixes cURL export and custom-method GUI execution, and improves the initial GUI layout.

## Compatibility

- Requires IntelliJ IDEA 2026.3, builds `263.0` through `263.*`.
- Use Kttp 1.0.1 for IDEA 2025.3 through 2026.2.
- Development and CI now use JDK 25.

## Fixes

- Prevent cURL export from executing the exported request's `then` and `thenResponse` callbacks, fixing JSON decoding and assertion failures during export.
- Preserve application interceptor configuration and prerequisite value resolution when exporting cURL.
- Load custom HTTP methods in the GUI and execute them through Follow Script.
- Fix PSI read access when importing or refreshing sidebar requests.
- Support delegated request results without a compatibility `getValue` extension.

## Improvements

- Set useful initial tool-window and navigation widths while preserving manual layout choices.
- Omit IDE-excluded and version-control-ignored files from Project script discovery and clarify sidebar source groups.
- Prefill new GUI drafts with an editable httpbin GET example, query parameter and Accept header.
- Allow CLI `--version` and `-v` without a script and report the packaged version.
- Update the English/Chinese documentation and Agent Skill for 1.1.0.

## Platform updates

- Replace the deprecated script-template classpath override with the Path-based Kotlin scripting API.
- Update the build toolchain and migrate CLI packaging to GradleUp Shadow.
- Keep CLI runtime dependencies separate from Kotlin classes supplied by the IDE.
- Enable native access for the CLI terminal library on Java 24 and later.

cURL export still evaluates top-level Kotlin and may execute prerequisite requests. cURL import is not included in this release.
